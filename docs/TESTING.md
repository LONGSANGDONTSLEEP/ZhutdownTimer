# 发布测试清单

## 自动验证

- `build.ps1` 在干净的 Windows GitHub Runner 上完成编译
- `--self-test` 验证时间格式、工作日计算、进度计算、参数解析、状态序列化、内嵌图标和主窗口初始化
- Inno Setup 安装程序完成静默安装
- 安装后的 `ZhutdownTimer.exe --self-test` 再次通过
- 便携 ZIP 和安装程序生成 SHA-256 校验值

## 发布前手工验证

- Windows 10 与 Windows 11：100%、125%、150% DPI
- 中文/英文切换后所有主界面、托盘、确认框、历史窗口文案完整
- 浅色、深色、跟随系统主题
- 倒计时和指定时刻计划
- 每天、工作日、周末的下一次时间计算
- 取消计划与最终确认“跳过本次”
- 睡眠、休眠、锁定使用真实机器验证
- 关机、重启、注销在保存工作后使用测试机器验证
- 开机自启开关写入/删除当前用户 Run 项
- 程序重启后恢复未到期计划；错过的一次性计划不补执行
- 安装、覆盖安装、卸载和便携版并行使用

真实电源操作不会在 CI 中执行；CI 使用 `--dry-run` 与纯逻辑自检避免关闭构建机。
